# אליאס

התיקייה הזו היא אתר שלם ומוכן, בלי שלב בנייה. כל טלפון שפותח את הלינק מקבל משחק נפרד משלו (רק המשחק בחדר עובר דרך Firebase).

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המשחק עצמו |
| `manifest.webmanifest` | מאפשר התקנה במסך הבית, עם שם ואייקון |
| `sw.js` | שומר את המשחק בטלפון כך שיעבוד גם בלי אינטרנט |
| `words/` | מאגרי המילים: `kids.txt`, `easy.txt`, `medium.txt`, `hard.txt` |
| `icons/` | האייקונים של האפליקציה |

## כתובת המשחק

**https://alias-liorhen9.web.app/**

האתר מתארח ב־Firebase Hosting, באתר `alias-liorhen9` בתוך פרויקט Firebase `alias-7214e` (אותו פרויקט של המשחק בחדר). כל דחיפה ל־`main` מתפרסמת שם תוך דקה או שתיים (`.github/workflows/deploy.yml`). אין שלב בנייה: הקבצים במאגר הם האתר, ו־`firebase.json` קובע אילו מהם עולים.

הכתובת הישנה, https://liorhen9.github.io/Alias/, מציגה רק מסך "אליאס עבר לכתובת חדשה" (`legacy-pages/`, מתפרסם ב־`.github/workflows/legacy-pages.yml`). שם נשאר גם `room.js`, כי 18Alias טוען אותו משם.

## עריכת המילים

כל המילים נמצאות בתיקייה `words`, בקובץ נפרד לכל רמה:

- `kids.txt`: כרטיסי הילדים. בכל שורה אימוג'י, רווח, ואז המילה. למשל: `🐘 פִּיל`
- `easy.txt`, `medium.txt`, `hard.txt`: מילים למבוגרים, מילה או צירוף אחד בכל שורה

שורות שמתחילות ב־`#` הן הערות, ומילים כפולות מסוננות אוטומטית.

איך עורכים ב־GitHub: נכנסים לקובץ, לוחצים על העיפרון ✏️, מוסיפים או מוחקים שורות, ולוחצים **Commit changes**. האתר מתעדכן תוך דקה או שתיים, ואין צורך לשנות שום קובץ אחר.

## עדכון המשחק בהמשך

1. מעדכנים את `index.html` (או קובץ אחר) ודוחפים ל־`main`.
2. ב־`sw.js` מעלים את המספר בשורה `const VERSION = "alias-v9";` ל־`alias-v10` וכן הלאה. ככה הטלפונים יודעים למשוך את הגרסה החדשה.
3. במאגר, תחת **Actions**, בודקים ש־`Deploy to Firebase Hosting` הצליח.

## התקנה במסך הבית

- **אנדרואיד (כרום):** במסך הפתיחה של המשחק מופיע כפתור "התקנה במסך הבית".
- **אייפון (ספארי):** כפתור השיתוף ⬆️ ואז "הוספה למסך הבית". המשחק מציג את ההסבר הזה בעצמו.

אחרי כניסה אחת עם אינטרנט, המשחק עובד גם בלי חיבור, כולל הגופנים.

## משחק בחדר (כל זוג בטלפון שלו)

במסך "מי משחק?" יש שני כפתורים: **פתיחת חדר** ו**הצטרפות לחדר**. מי שפותח את החדר מגדיר רק את הזוג שלו, ומקבל קוד ו־QR. כל זוג אחר מצטרף מהטלפון שלו ומגדיר את עצמו: סורק את ה־QR במצלמה של הטלפון, או לוחץ "הצטרפות לחדר" באפליקציה וסורק משם או מקליד את הקוד (אפשר להקליד גם במקלדת עברית, האותיות מתורגמות לבד). אין צופים: כל טלפון בחדר הוא זוג במשחק, ואפשר להצטרף רק לפני שהמארח מתחיל.

- **התור** רץ בטלפון של הזוג שמשחק. בשאר הטלפונים רואים את הטיימר, הניקוד והמילים שכבר נענו.
- **"הזוגות האחרים רואים את המילה"**: הגדרה של המארח, כדי לתפוס מי שאומר חלק מהמילה. אפשר להפעיל אותה רק כש"המילה האחרונה" כבויה. גם באמצע המשחק המארח יכול להדליק ולכבות אותה בכפתור ⚙️ שבפס העליון, והשינוי חל מיד, גם באמצע תור.
- **אישור הסיכום**: בסוף כל תור הזוג הבא בתור מאשר את הסיכום, ויכול לתקן מילים. המארח יכול לאשר במקומם אם הם לא מגיבים.
- **טלפון שנטען מחדש** חוזר למשחק. אם זה הטלפון שבאמצע התור, התור חוזר מושהה בדיוק מאותה נקודה.
- **יצאתם בטעות?** מי שלחץ ✕ ויצא מהחדר רואה במסך הפתיחה כפתור "חזרה לחדר" וחוזר בדיוק לאותה נקודה. אם חוזרים מטלפון אחר או מדפדפן אחר (למשל סריקת QR במצלמה כשהמשחק מותקן במסך הבית), נכנסים לחדר בלינק או בקוד ובוחרים את הזוג שלכם מתוך הזוגות שלא מחוברים כרגע. המארח מקבל בקשה ומאשר אותה (או לא), ורק אז הטלפון החדש ממשיך לשחק. הזוג של המארח לא מופיע שם.
- הקוד כולו נמצא ב־`room.js`, ומשותף ל־Alias ול־18Alias (18Alias טוען אותו מכאן). המשחק הרגיל בטלפון אחד לא משתנה וממשיך לעבוד בלי אינטרנט.

### הגדרת Firebase

החדר משתמש ב־Firebase Realtime Database (חינמי בהיקף הזה). ההגדרות כבר נמצאות ב־`room.js`. בקונסולה צריך:

1. **Authentication → Sign-in method**: להפעיל את **Anonymous**.
2. **Realtime Database → Rules**: להדביק את התוכן של `database.rules.json` מהמאגר הזה ולפרסם (Publish). בכל פעם שהקובץ הזה משתנה, מדביקים מחדש.
3. **Authentication → Settings → Authorized domains**: אפשר להוסיף את `alias-liorhen9.web.app` (כניסה אנונימית עובדת גם בלי זה).

### בדיקה בלי Firebase

מוסיפים `?roomdev` לכתובת. החדר יעבוד בין לשוניות באותו דפדפן, וכל לשונית מתנהגת כמו טלפון נפרד.

## פרסום ב־Firebase Hosting (הקמה חד־פעמית)

הפריסה האוטומטית צריכה מפתח שירות של הפרויקט `alias-7214e`, שמור כסוד ב־GitHub:

1. ב־Firebase ← ⚙️ ← **Project settings** ← **Service accounts** ← **Generate new private key** ← **Generate key**. יורד קובץ `.json`.
2. פותחים אותו בפנקס רשימות ומעתיקים את כל התוכן.
3. https://github.com/LiorHen9/Alias/settings/secrets/actions ← **New repository secret**. שם: `FIREBASE_SERVICE_ACCOUNT`, ובתוכן מדביקים. **Add secret**.
4. מוחקים את הקובץ שירד (גם מסל המיחזור).
5. הרשאה לפרסם: באותו מסך **Service accounts** מעתיקים את המייל של חשבון השירות (מתחיל ב־`firebase-adminsdk-`), נכנסים ל־https://console.cloud.google.com/iam-admin/iam?project=alias-7214e, בשורה של אותו מייל לוחצים ✏️ ← **Add another role** ← **Firebase Hosting Admin** ← **Save**.
6. בדיקה: **Actions** ← **Deploy to Firebase Hosting** ← **Run workflow**. אחרי דקה צריך להופיע ✓ ירוק.

אפשר לפרסם גם מהמחשב: `firebase deploy --only hosting`.

### המעבר מ־GitHub Pages

1. מוודאים שהכתובת החדשה עובדת.
2. בכל טלפון: פותחים את האייקון הישן (או את הכתובת הישנה). מופיע מסך המעבר עם כפתור לכתובת החדשה. מתקינים אותה במסך הבית ומוחקים את האייקון הישן. אין מה לגבות: נשמר בטלפון רק המשחק הנוכחי.
3. **לפני שהופכים את המאגר לפרטי**: 18Alias טוען את `room.js` מהכתובת הישנה (`../Alias/room.js`). כשהמאגר יהיה פרטי, GitHub Pages ייסגר והחדר ב־18Alias יפסיק לעבוד. לכן קודם מעבירים גם את 18Alias (או נותנים לו עותק משלו של `room.js`).
4. אחר כך: **Settings** ← **General** ← **Change visibility** ← **Make private**. האתר הישן ייסגר מעצמו.
