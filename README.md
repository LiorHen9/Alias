# אליאס: הוראות העלאה

התיקייה הזו היא אתר שלם ומוכן. אין שרת ואין מסד נתונים, כל טלפון שפותח את הלינק מקבל משחק נפרד משלו.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `index.html` | המשחק עצמו |
| `manifest.webmanifest` | מאפשר התקנה במסך הבית, עם שם ואייקון |
| `sw.js` | שומר את המשחק בטלפון כך שיעבוד גם בלי אינטרנט |
| `icons/` | האייקונים של האפליקציה |

## העלאה ל־Netlify (הכי פשוט, מומלץ ממחשב)

1. פותחים את https://app.netlify.com/drop
2. גוררים את קובץ ה־zip (או את התיקייה `alias-site`) לאזור ההעלאה.
3. תוך כמה שניות מתקבלת כתובת שמסתיימת ב־`netlify.app`.
4. **חשוב:** בלי חשבון, האתר מוגן בסיסמה זמנית. כדי שכל אחד יוכל להיכנס, נרשמים בחינם ולוחצים על האפשרות לשייך (Claim) את האתר לחשבון.
5. רוצים כתובת יפה יותר? בהגדרות הפרויקט אפשר לשנות את השם, למשל `alias-family.netlify.app`.

## עדכון המשחק בהמשך

1. מחליפים את `index.html` בגרסה החדשה.
2. ב־`sw.js` מעלים את המספר בשורה `const VERSION = "alias-v1";` ל־`alias-v2` וכן הלאה. ככה הטלפונים יודעים למשוך את הגרסה החדשה.
3. בלוח הבקרה של הפרויקט ב־Netlify, תחת Production deploys, גוררים שוב את התיקייה. הכתובת נשארת אותה כתובת.

## התקנה במסך הבית

- **אנדרואיד (כרום):** במסך הפתיחה של המשחק מופיע כפתור "התקנה במסך הבית".
- **אייפון (ספארי):** כפתור השיתוף ⬆️ ואז "הוספה למסך הבית". המשחק מציג את ההסבר הזה בעצמו.

אחרי כניסה אחת עם אינטרנט, המשחק עובד גם בלי חיבור, כולל הגופנים.
